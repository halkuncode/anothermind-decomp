Debug menu: 

Set 0x01 to RAM address 0x8012C994 to enable the debug mode.
Press Start to display a CPU meter and the debug menu.
 
Press L1, R1 to change the background.
Press L2, R2 to change debug screens.
Press Start + Select to go to the title screen. and turns off debug


MAIN MENU

OK 	Exit menu
BASICS* SYSTEM 	Displays some information of scenario or memory data.
STEP 	Execute script step by step.
LABEL 	Displays the script's current label.
WATCH 	Displays "WATCH". (Turns On Watch)
WATCH16: HEX* BINARY 	Displays 16 bit values as hex or binary
WATCHFLAG 	Displays flag values.
CODE: 0000 	show script commands executed: (Number of lines ) 
TAIWA(対話; Talk) 	Displays a talk system parameter.
MSPEED0 	Set message speed to fastest.
FLAG* GLOBAL 	Display memory viewer.
